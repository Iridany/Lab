##  Технические детали выполнения Лаб.1

### Стек технологий
- **IDE:** GigaIDE (2025.1)
- **Java:** OpenJDK 26.0.1
- **JavaFX:** SDK 26.0.1
- **Система сборки:** IntelliJ (модули)
- **VCS:** Git + GitHub


### Функциональность конвертера
- **3 единицы:** чашки (cup), жидкие унции (fl oz), миллилитры (ml)
- **Дробные числа:** поддержка чисел с плавающей точкой
- **Обработка ошибок:**
  - Пустое поле → "Введите значение"
  - Не число → "Введите корректное число"
  - Отрицательное число → "Введите положительное число"
